# 🍕 Plato's Pizza – Sales Analysis (2015)

## 📊 Project Overview
This project presents a business analysis of **Plato's Pizza** for the year **2015**, created in Power BI.  
The goal is to provide insights into sales performance, product trends, and customer behavior to support data-driven decision-making.

---

## 📁 Data Sources
- Source data is stored in **CSV files**
- Data is loaded and transformed in Power BI
- Tables are connected within a **data model** to enable analysis across multiple dimensions

---

## 🧩 Data Model
The dataset consists of multiple related tables (e.g. orders, pizzas, categories), which are:
- cleaned and transformed in Power Query
- connected via relationships in the data model

This structure allows for efficient filtering and aggregation across the report.

---

## 📈 Report Structure
The Power BI report contains **4 pages**:

### 1. 🏠 Title Page

### 2. 📊 Overview
- Key business metrics (e.g. total sales, number of orders)
- High-level trends and performance indicators

### 3. 🍕 Product Analysis
- Best-selling pizzas
- Sales by category and size
- Product performance comparison

### 4. 👥 Customer Behavior
- Order patterns over time
- Peak hours and days
- Insights into customer purchasing behavior

---

## 🛠️ Tools & Technologies
- **Power BI (.pbix)**
- Data transformation: **Power Query**
- Data modeling: relationships between tables
- Data source format: **CSV**

---

## ▶️ How to Use
1. Download the `.pbix` file
2. Make sure the **CSV source files** are available
3. Open the file in **Power BI Desktop**
4. If needed, update the data source paths

---

## 📌 Notes
- If data source paths are broken, simply reconnect them to the provided CSV files  
- All visuals are interactive and support filtering across the report

---

## 🎯 Key Objective
To demonstrate the ability to:
- clean and transform raw data
- build a relational data model
- create meaningful and interactive visualizations
- extract actionable business insights
